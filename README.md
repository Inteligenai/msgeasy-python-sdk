# msgeasy (Python)

Source mirror of `packages/sdk-python` from [Inteligenai/msgeasy](https://github.com/Inteligenai/msgeasy).
Source, issues, and PRs live in that repo -- this one exists only so `pip install` can pull a
git-hosted release without needing access to the private monorepo.

```bash
pip install "git+https://github.com/Inteligenai/msgeasy-python-sdk.git@v0.1.0"
```

Pushed automatically by `.github/workflows/publish-sdk-python.yml` on every `sdk-python-v*` tag.
Do not edit here directly -- changes belong in the source repo.
